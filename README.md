## Things I build

### [Argo](https://github.com/gigioneggiando/argo) · software security

Argo helps me review source code for vulnerabilities with language models. I design the workflow, check the findings and report confirmed issues to maintainers. The [public findings archive](https://gigioneggiando.com/argo/findings.html) links to advisories, fixes and the evidence behind them.

### [Ager](https://agerculture.com) · news and information

A link-first news project I co-founded and build end to end, from the .NET backend and Next.js frontend to PostgreSQL and the infrastructure it runs on. It keeps readers close to the original sources.

## Along the way

At SDU, I contributed to [Beyond Patching](https://portal.findresearcher.sdu.dk/en/projects/beyond-patching-empowering-organizations-to-stay-ahead-of-softwar/) and continue collaborating on AI and software security research. I help students with Operating Systems as a teaching assistant. In November, I'll join Danfoss as a Student Worker in CRM Delivery.

Most of my work uses `Python`, `C# / .NET`, `TypeScript`, `PostgreSQL` and `Docker`.

Away from code, I return to philosophy, literature and cinema. Some of the questions they leave me with are in my [notebook](https://gigioneggiando.com/notebook.html).
